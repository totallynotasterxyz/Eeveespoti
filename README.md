# EeveeSpoti

**Combined EeveeSpotifyReincarnated + spoti.pw**

One IPA. Premium spoof from Eevee. Liquid Glass redesign, word-by-word lyrics, audio effects and Live Activity from spoti.pw. No conflicts.

## How it works

- **EeveeSpotifyReincarnated** handles the real premium spoofing (skip, high quality, no ads, etc.)
- **spoti.pw** provides the modern UI (Liquid Glass), advanced lyrics, EQ/effects, Live Activity
- spoti.pw's own Spoof Premium toggle is left **off** by default so the two mods don't fight

## Recommended Spotify version

- **9.1.78** (best for current spoti.pw)
- Eevee currently supports up to ~9.1.84

## Usage

1. Get a **decrypted** Spotify IPA (decrypt.day, BagBak, etc.)
2. Go to Actions → "Build Combined Eevee + spoti.pw IPA"
3. Run the workflow with the direct download link to your IPA
4. Download the resulting combined IPA from the workflow artifacts
5. Sign with SideStore / Feather / AltStore / your cert
